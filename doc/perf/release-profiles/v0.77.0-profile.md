# v0.77.0 Release Performance Profile

## Scope

Second real-input scroll profile. It records the floor experiment that bounded the target, the three costs removed (scroll-time hover work under mouse-wheel input, List-body re-runs on selection, 500-row page application), the two attempts that measured as no gain, and the steady-state result.

## Environment And Input

- Date: 2026-09-02
- Host: Apple M3 Pro (5P+6E), 36GB, arm64, 120 Hz display; macOS 15.7.3 (`24G419`); Xcode 26.1.1 (`17B100`)
- Configuration: Release, driven by `scripts/perf-scroll/profile_scroll.py`; the terminal is trusted for Accessibility
- Snapshot DB: `perf-db/clipboard.db`, 9,566 rows (2,481 images); "fresh" = a new copy per run (regenerates thumbnails, ~0.7 s off-main, and re-runs the List body per thumbnail), "steady" = `--reuse-db` (one warmed copy under `logs/perf-scroll/db-warm`)
- Panel: the real `FloatingPanel` via `SCOPY_PROFILE_OPEN_PANEL=1`, 480x640
- Wheel workload: pixel scroll-wheel `CGEvent`s, 24 px at 60 Hz, direction flipped every 4 s, 12 s, cursor over the list; "mouse-like" has no gesture phase, "trackpad-like" (`--phased`) carries began/changed/ended phases
- Pointer: the maintainer's Accessibility pointer customization is still present; `ScrollCursorSetCoalescer` (v0.76.0) keeps it out of the numbers

## Findings (Scopy v0.76.0, mouse-like wheel, fresh DB)

| Cost | Cause |
| --- | --- |
| `322` hover sessions per 12 s, `2-5 s` of off-main `CGImageSourceCreateThumbnailAtIndex` | Legacy wheel events post no live-scroll notifications, so `isScrolling` stayed false and rows passing under the pointer started sessions and preview decodes (50 ms after hover) |
| `75 ms` callback at the first page load, then 25 ms callbacks for ~0.8 s | `loadMorePageSize` 500: SwiftUI initializes every ForEach child on a List body run, each new row paid a descriptor miss (SHA-256 + text metrics) in `HistoryItemView.init` |
| `~50 ms` main-thread burst after a scroll ends | Hover-select wrote `selectedID`, which the List body read; `OutlineListCoordinator.diffRows` / `ViewListTree.getIDs` over every loaded item plus one `HistoryItemView.init` per child |

## Fixes

- Unified scroll state from clip-view `boundsDidChange` + live-scroll notifications (`ListLiveScrollObserverView`, 120 ms settle, `ListProgrammaticScrollGate` for keyboard follow).
- `HistoryRowSelectionFanout` + `HistorySelectionAwareRow`: selection updates two rows, never the List body.
- `loadMorePageSize` 100; lazy row descriptor; memoized revisions in display-text prewarm; `layout()` no longer re-resolves the scroll view once attached; `passiveHistoryRowEnabled` read once.

## Measured As No Gain (reverted)

- Per-row `.onHover` replaced by one list-level tracking area plus a per-row marker `NSViewRepresentable`: `4.41 -> 4.50 s`; `PointerRegionUpdater` stayed at 3.5% because it runs from `NSHostingView.updateRemovedState` on cell reinsertion, and the marker platform view cost 1.7%.
- `.background{}`/`.overlay{}`/`.animation` merged into one conditional node: `3.40 -> 3.40 s` main thread; the floor's gain came from hover churn.

## Results

| Metric | v0.76.0 | v0.77.0 |
| --- | ---: | ---: |
| Mouse-like: Scopy CPU, fresh DB | `9.94 s` | `3.03 s` |
| Mouse-like: Scopy CPU, steady state | n/a | `2.83-2.87 s` |
| Mouse-like: main thread busy | `5.02 s` (42%) | `2.61-2.65 s` (22%) |
| Mouse-like: hover sessions during scroll | `322` | `2` |
| Mouse-like: callback p95 / max | `16.7 / 25-42 ms` | `8.3 / 16.7-25 ms` |
| Trackpad-like: Scopy CPU / main thread | `4.50 / 3.37 s` (28%) | `2.74 / 2.44 s` (20%) |
| Trackpad-like: callback p95 / max | `8.3 / 83.3 ms` | `8.3 / 16.7 ms` |

Intermediate steps, mouse-like, fresh DB: unified scroll state alone `9.94 -> 4.41 s` (main `5.02 -> 3.41 s`); page size 100 + lazy descriptor removed the 75 ms callback; selection fan-out removed the post-scroll List diff.

Remaining main-thread work (steady state, share of samples): CA commit + hosting layout ~14%, AttributeGraph ~11%, `NSTableView` recycling ~8%, legacy `scrollWheel` delivery ~7%, `OutlineListCoordinator` ~6%, automatic row heights ~5%.
