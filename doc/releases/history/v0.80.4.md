# v0.80.4

## Summary

Render original Codex file, media and application icons, restore source favicons, and preserve artwork colors in PNG exports.

## Key Changes

- Ordinary web links, citations and result-card sources share exact-host favicon selection, including verified EleBank and HSBC HK artwork. Frozen favicons are bounded by an aggregate output budget; linked images retain their own presentation.
- Replace substitute file/source artwork with original SVGs from installed Codex 26.901.41600 (build 7982). Cover file types, images, Office documents, code languages, audio/video attachments, 22 application brands, and seven rich controls. Preserve original paths, paint, gradients and viewBoxes with unique instance paint IDs.
- Align file/app labels using the source-declared icon sizing and spacing. Recognize `app://`, `plugin:` and `plugin://…@marketplace` brands while keeping application mentions inert.
- Preserve SVG fill rules and root paint through sanitization. Inspect the ready DOM before PNG encoding so palette reduction cannot shift branded colors, including the purple bank and media icons.
- Keep one shared preview/export renderer. Audio/video file classification adapts Codex attachment artwork; the currency selector retains its existing combined up/down glyph because an equivalent Codex component was not found. Original asset provenance is recorded in `Tools/MarkdownRenderer/THIRD_PARTY_NOTICES.md`.
