# v0.8.8

## Summary

This patch ships the first two measured frontend scroll optimizations from the Xcode 27 beta audit: row descriptor reuse and lazy Markdown PNG export capability checks. Thumbnail decoding remains intentionally unchanged for a later pass.

## Key Changes

### Frontend Scroll Performance

- Adds a row descriptor cache to `HistoryItemPresentationCache`, keyed by clipboard item identity, row-relevant settings, preview metadata, thumbnail metadata, and app icon state.
- Routes `HistoryItemView` initialization through the shared row descriptor cache so repeated SwiftUI row construction does not rebuild the same display model during scroll.
- Removes exact Markdown PNG capability detection from `HistoryItemRowDescriptor`, keeping row display construction focused on preview text, file preview metadata, thumbnail metadata, and app icon metadata.
- Adds a fast Markdown signal for context-menu offering, while preserving the exact `canExportPNG` check at export time.
- Stops text-row prewarm from populating Markdown capability cache entries; file preview prewarm remains in place.

### Profiling Harness

- Replaces the hidden SwiftUI `MenuBarExtra` scene with a `Settings` scene to avoid the internal `Item-0` window observed in Xcode 27 beta accessibility snapshots.
- Adds a frontend profile harness switch that skips the profile-only XCUITest list query, avoiding recursive Xcode 27 beta accessibility hierarchy failures while preserving app-side scroll instrumentation.
