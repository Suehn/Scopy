# v0.70.0

## Summary

`v0.70.0` upgrades Scopy's single Markdown preview/export pipeline with interactive ChatGPT-style rich response surfaces and closes the first-hover blank and scroll-flicker lifecycle defects. The implementation is responsive by design rule rather than hard-coded to any supplied screenshot size.

## Key Changes

### Strict Rich Surfaces

- Adds versioned `scopy-rich` v2 envelopes for web results, image groups, news, weather, finance, and currency.
- Validates every envelope before promotion. Unknown types, unsupported versions, excessive input, ambiguous assets, and invalid data remain literal code fences.
- Uses only bundled allowlisted images and favicons; rendering performs no remote asset fetch and does not infer missing cards from neighboring prose.
- Keeps weather/day, finance/range, currency, chart-probe, image-lightbox, and source-popup interactions active in preview. PNG export freezes that same DOM and disables actions before capture.

### Links And Citations

- Opens only validated absolute HTTP(S) destinations after an explicit preview click and renders the local Phosphor outbound-link affordance.
- Supports Codex-style absolute local file destinations with optional one-based line/column suffixes while rejecting raw `file:` URLs, relative or double-slash paths, remote hosts, credentials, queries, fragments, controls, and programmatic navigation.
- Keeps ordinary links, Codex file links, and source citations separate. Grouped citations retain real supporting destinations in a keyboard-accessible popup without inventing hidden sources.

### Preview Lifecycle Stability

- Removes the hidden Markdown premeasurement view that competed with the visible popover for one reusable `WKWebView`.
- Gives every visible representable an ownership lease so stale dismantle callbacks cannot detach or cancel a newer owner.
- Makes bridge attachment and identical in-flight HTML loads idempotent, and retries scroll configuration until WebKit's internal scroll view exists.
- Preserves the existing render-ID/main-frame readiness gates so late navigation output cannot replace current preview state.

### Real Clipboard And Fixture Coverage

- Preserves related authored Markdown from mixed HTML/plain-text clipboard representations without accepting unrelated side-channel text.
- Adds `user_markdown_stress.md`, the user's full 47,419-byte, 2,728-line Markdown/math/table/Unicode stress document.
- Adds `chatgpt_rich_copy_sample.md`, the user's copied visible text. Because that source contains no structured private payload or real destinations, it deliberately renders as ordinary Markdown and does not synthesize rich cards or citations.
- Keeps `chatgpt_rich_surfaces.md` as the deterministic strict-v2 structured fixture for all supported card and interaction states.

## Evidence Boundary

The inspected WACZ is a valid, parseable archive containing runtime code, styles, resources, saved text, and selected structured response data. It does not contain a hydrated completed-answer DOM or computed-style snapshot, so the release does not claim that the archive alone proves pixel-exact final geometry, dark-mode parity, or a computed body font. Current visuals are supported by the supplied reference captures, live browser inspection already recorded for this work, current renderer tests, and real Scopy exports.
