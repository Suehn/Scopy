# v0.80.7

## Summary

Remove the top toolbar strip introduced in v0.80.6 and restore the earlier Markdown line breaks and display scaling. Multiple independent pinned windows remain available.

## Key Changes

- Replace the reserved 34 pt toolbar row in text, image and file previews with compact floating controls. Window actions sit at the lower leading edge; Markdown scale and export controls sit at the upper trailing edge. Short pinned documents keep their controls at the window edge. An explicit move grip leaves text selection available.
- Restore the canonical 816 px Markdown surface and logical viewport of `816 / selectedScale`. Narrow windows apply display-only fit; wider windows center the surface without enlarging or reflowing it. Preview and PNG retain the same renderer and assets.
- Keep per-window scale, scroll position, frame, floating state and ownership. Invalidate cached document wrappers for the restored layout.
