# v0.71.0

## Summary

`v0.71.0` hardens the single Markdown preview/export pipeline and closes the rich-surface fidelity gap against the captured ChatGPT desktop references. It ships the closed safe-HTML extension, the public image-group presentation adapter with exact-URL local assets, the lockfile-derived atomic renderer asset contract, the terminal-readiness preview lifecycle, math outcome counting, and a rich fidelity pass whose structural core is one decision: the 816px output surface now renders the canonical 48rem desktop column at 100% scale.

## Key Changes

### Safe-HTML Extension And Literal Residue

- Recognizes only attribute-free, correctly paired `u`, `kbd`, `mark`, `sub`, and `sup` phrasing plus the exact block `details`/plain non-empty `summary` form as trusted AST nodes; complete HTML comments disappear outside code.
- Every unsupported, attributed, malformed, mismatched, flow-wrapping, or excessively nested form stays visible escaped text, and `<script>` can never become an element. Preview toggles `details`; export freezes it open and removes interaction.

### Public Copy Determinism

- Two or more consecutive image-only Markdown paragraphs reuse the image-grid/lightbox presentation using only their visible `src`/`alt`/`title`; nothing reconstructs a missing card, source, date, citation, or private metadata.
- The two exact ChatGPT Search documentation URLs preserved by the public-copy fixture render from bundled local raster assets; every other remote image keeps the deterministic offline fallback, enforced by the document CSP (`img-src 'self' data:`).

### Atomic Renderer Asset Contract

- The renderer IIFE, its SHA-256 sidecar, KaTeX 0.16.45 CSS, all 60 CSS-referenced KaTeX fonts, and `asset-manifest.json` are generated and verified as one `package-lock.json`-derived set (`npm run build` / `npm run verify:assets`).
- `make build`/`make test*` gate on repository asset verification; the release script verifies the staged tree inside the built app and fails on any flat duplicate resource.

### Terminal Readiness Lifecycle

- A render is terminal only after the renderer, canonical stylesheet, `document.fonts`, every local image outcome, task/rich hydration, two paint frames, and the current layout epoch resolve; the reusable WebView stays transparent behind the SwiftUI shield until current-owner success, and terminal failure keeps the source plus reason visible.
- Metric caching requires the exact active layout scale; ResizeObserver/toggle bursts coalesce through requestAnimationFrame; export throws on a non-terminal DOM instead of snapshotting partial output. Navigation failures and web-content-process termination surface as visible failures scoped to the owning render.

### Rich Fidelity Pass

- The wide-thread threshold now equals the 816px output surface: 100% scale and zoom-out render the 48rem desktop column that matches the captured ChatGPT references, while zooming in selects the narrow 40rem reading column with its contractual locally scrolling card tracks. This removes the clipped third news card, the clipped eighth weather day, the clipped hourly chart edge, and the two-column finance metrics of the previous default.
- Chart trend and weather-warm colors are single-source `--scopy-rich-*` tokens sampled from the desktop reference screenshots; SVG gradient stops inherit `currentColor`, so no chart color exists outside the stylesheet. Sampling confirmed the palette values themselves already matched, and none changed.
- Source citations may show a bundled favicon only through a closed exact-host map (seven hosts onto the four bundled favicon assets); every other citation keeps the deterministic globe and nothing fetches. Finance metrics follow the reference three-column order, currency amounts use medium-weight tabular numerals, and Codex-style file-link icons gain a 1.15 optical scale that compensates for Phosphor grid padding without touching licensed path data.

### Math Observability And Source Purity

- The renderer reports `mathStrictCount`, `mathRelaxedCount`, and `mathErrorCount` from real KaTeX outcomes; the relaxed retry now throws on failure so broken input always reaches the stable literal `.katex-error` surface.
- Authored/ChatGPT sources bypass the scientific math pre-processing byte-for-byte; only the explicitly detected OCR/scientific profile may repair input. The contract records the precise remark-math semantics: single-line `$$x$$` is inline math and only the standalone block form is display math.
