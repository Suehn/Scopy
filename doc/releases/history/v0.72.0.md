# v0.72.0

## Summary

`v0.72.0` completes the rich-surface vocabulary, closes the public-copy gap as far as honesty allows, and adds the first sanctioned network paths around the still fully offline renderer: five new strict v2 card types, closed public-copy shape adapters, opt-in Open Graph link enrichment (default off), and Sparkle-based automatic update reminders with install-and-relaunch.

## Key Changes

### Complete Strict v2 Card Vocabulary

- Adds `video` (play-badged media card), `product` (badge, price with strike-through original, half-star-quantized local rating stars, merchant), `product_carousel` (locally scrolling four-per-row track, 2–10 items), `entity` (place card with category/rating/price level/address/phone/hours), and `map` (frozen static map image plus a numbered pin list; nothing fetches tiles).
- Every type is validated by the same closed `normalizeRichSurface` authority with hard limits; invalid envelopes stay literal code fences. Three Phosphor glyphs (`star-fill`, `map-pin-fill`, `play-fill`) join the closed icon set byte-identical to upstream 2.1.1.

### Public-Copy Shape Adapters

- A real ChatGPT public copy now yields cards wherever its visible fields are complete: a lone YouTube link becomes a video card, a link (or `### [title](url)` heading) followed by a price-only paragraph becomes a product card, and a name/link/`Address:` block becomes a place card that absorbs its duplicated bare-name paragraph. The reference public-copy fixture renders eight cards instead of one.
- The honest ceiling is contract-recorded: ChatGPT's Copy strips card payloads at the source, so surfaces whose copy lacks the data (bare-link news without enrichment, stocks, weather) remain ordinary prose rather than fabricated cards.

### Opt-In Link Enrichment (default off)

- A new backend fetcher may retrieve Open Graph titles, sources, dates, snippets, and downscaled data-URI imagery for the bare links of recognized assistant content (ChatGPT web copies via `utm_source=chatgpt.com` link rewriting, Codex output via absolute local file links, and citation-structured assistant markdown). Requests are cookie-less, size- and time-capped, and restricted to public hosts.
- Results freeze into content-hash-keyed sidecars; the renderer consumes only frozen data through the ordinary v2 `news`/`web_results` validators, the sidecar fingerprint participates in every render and metric cache key (renderer version bumped to v6), and the hover preview re-renders live when enrichment lands. The setting gates fetching only — rendering, preview, and export never perform network access and the document CSP is unchanged.

### Automatic Updates

- Integrates Sparkle 2.9.6: daily update checks with a reminder prompt and install-and-relaunch on confirmation, plus a "检查更新…" button in the About settings page. The feed lives at the stable `releases/latest/download/appcast.xml` URL and update archives are EdDSA-verified against the public key shipped in Info.plist.
- The release workflow generates and attaches a signed `appcast.xml` using the `SPARKLE_ED_PRIVATE_KEY` repository secret and emits a loud warning instead of silently skipping when the secret is missing.

## Evidence Boundary

Card styling for the new types follows ChatGPT's published design language plus the existing card token system and is labeled a Scopy adaptation pending captured references; token single-sourcing (`--scopy-rich-rating-star`, `--scopy-rich-map-pin`, `--scopy-rich-media-bg`) keeps later pixel calibration one-line. No new pixel-perfect, dark-mode, or computed-font claim is made.
