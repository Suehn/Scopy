# v0.65.4

## Summary

`v0.65.4` replaces Scopy's accumulated Markdown compatibility paths with one local renderer and one document-building path shared by hover preview and PNG export. Its semantics, typography, spacing, responsive width, overflow behavior, and edge-case handling are aligned to the completed ChatGPT response captured in `my-archiving-session.wacz`, with explicit tests for the parts that can be reproduced locally.

## Key Changes

### One Renderer Contract

- Routes preview and PNG export through `MarkdownHTMLRenderer -> MarkdownHTMLDocumentBuilder` using the same parsed HTML and base CSS.
- Removes the renderer selector, shadow comparison, feature flags, markdown-it fallback, safe-HTML restoration path, duplicate math/CJK normalizers, and their obsolete bundled assets and tests.
- Treats a missing renderer asset as an explicit error instead of silently changing semantics.

### ChatGPT-Aligned Semantics And Layout

- Renders CommonMark/GFM headings, lists, tasks, tables, links, images, code, footnotes, citations, and local HTML-only KaTeX in one unified/remark/rehype pipeline.
- Uses stable `scopy-fn-*` / `scopy-fnref-*` fragment IDs, literal display for user-authored raw HTML, and syntax-aware normalization that protects code, URLs, file paths, links, images, and reference definitions.
- Applies the captured completed-message typography and rhythm: 16/26 body text, 24/32 h1, 20/28 h2, 18/28 h3, 16/24 h4, 4px paragraph rhythm, 16px adjacent-paragraph separation, 26px list inset, and 24px/8px/4px blockquote geometry.
- Models ChatGPT's logical 40rem/640px thread width and conditional 48rem/768px desktop width inside Scopy's fixed 816px render surface, including 80%...200% layout profiles without tying content width to the physical WebView.
- Keeps local horizontal overflow for code, display math, and tables while ordinary prose wraps safely; table overflow does not widen the hover popover.

### Stable Preview And Export

- Assigns every WebView navigation a render ID and accepts readiness or metrics only from the current main-frame load. Metric identity includes overflow and success/error state as well as geometry.
- Keeps export fitting downstream of preview-equivalent layout so PNG generation cannot invoke a second parser or stylesheet.
- Adds long-form export coverage and renderer cases for CJK/RTL/Unicode, missing ATX-heading whitespace, table code-span pipes, raw HTML, math delimiters, footnotes, citations, tasks, wide tables, and malformed input.

### Engineering Guidance

- Updates `AGENTS.md`, `CLAUDE.md`, and the canonical product, architecture, development, and WACZ rendering-contract documents to require the simplest end-to-end implementation, removal of obsolete compatibility paths, modular boundaries, existing dependencies first, and long-term rather than stopgap architecture.
