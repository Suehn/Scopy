# v0.82.1

## Summary

- Fix Homebrew installation on macOS 15 and later

## Key Changes

- Both Homebrew casks use `depends_on macos: ">= :sonoma"`. Older Homebrew versions interpret the previous bare `:sonoma` as an exact OS requirement and reject macOS 15 and newer before installation.
- The app's deployment target remains macOS 14.0. The cask has no maximum OS version; this removes the installer restriction without claiming runtime testing on every future macOS release.
- Includes the three post-v0.82.0 main-branch corrections: the source-icon loader closure is `@Sendable`, the missing-stylesheet test accepts either terminal reason, and string-loaded export tests identify renderer-blocked hosts.

## Verification

- `make build`, `make docs-validate`, `make release-validate`, and `make test-release-policy` pass (15 policy tests).
- Both Homebrew 4.6 and local Homebrew 7 parsers resolve the explicit requirement as `>= 14`; 14, 15, 26, and 27 pass the version comparison and 13 is rejected.
- The local unit run on unchanged main-branch application/test sources completed 829 tests with 2 skips and 17 failure events across 9 test cases, involving WebKit paint/rendering and pngquant process cancellation. This release does not claim a green full runtime suite. Strict tests are not rerun for this install-only patch under the maintainer's rapid-release request; no application or test source is changed by this release commit.
- Release commit: `5988e57b95d266b1672a6b03893832c844061073`. [Release build](https://github.com/Suehn/Scopy/actions/runs/38416239825) published the DMG, checksum, and Sparkle appcast. The external tap automation failed; manual push `eb5a305` completed the synchronization. Main cask commit `ae1478f` and tap cask `eb5a305` are identical.
- DMG SHA-256: `b5872ecfcfd21a12a132c67cda91866e45f0ba7d8009bd3dddf59ce7d95f9878`. The downloaded DMG matches the published checksum.
- Fully qualified `brew fetch` and `brew reinstall --cask Suehn/scopy/scopy --force --appdir=/Applications` pass on macOS 15.7.3. Installed bundle: version `0.82.1`, build `659`, minimum macOS `14.0`, `x86_64 arm64`. All installed app files match the mounted DMG; the app launches from `/Applications`.
- Hosted TSan [passed](https://github.com/Suehn/Scopy/actions/runs/38416215173). General [CI](https://github.com/Suehn/Scopy/actions/runs/38416215881) is not fully green; installation acceptance does not replace runtime-test results.
- Newer Homebrew prints a deprecation warning for the explicit comparison syntax but installation succeeds. This spelling is retained so older Homebrew also accepts newer macOS releases. macOS 27 runtime behavior was not tested.
- No new performance profile: this release changes the install requirement and includes the small corrections listed above, with no performance claim.

## Installation

After the release is published, run `brew update` and `brew upgrade --cask Suehn/scopy/scopy`. New users can run `brew install --cask Suehn/scopy/scopy`.
