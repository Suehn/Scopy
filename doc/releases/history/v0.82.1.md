# v0.82.1

## Summary

- Fix Homebrew installation on macOS 15 and later

## Key Changes

- Both Homebrew casks use `depends_on macos: ">= :sonoma"`. Older Homebrew versions interpret the previous bare `:sonoma` as an exact OS requirement and reject macOS 15 and newer before installation.
- The app's deployment target remains macOS 14.0. The cask has no maximum OS version; this removes the installer restriction without claiming runtime testing on every future macOS release.
- Includes the three post-v0.82.0 main-branch corrections: the source-icon loader closure is `@Sendable`, the missing-stylesheet test accepts either terminal reason, and string-loaded export tests identify renderer-blocked hosts.

## Verification

- `make build`, `make docs-validate`, `make release-validate`, and `make test-release-policy` pass (15 policy tests).
- Both Homebrew 4.6 and local Homebrew 7 parsers resolve the explicit requirement as `>= 14`; 14, 15, 26, and 27 pass the version comparison and 13 is rejected.
- The local unit run on unchanged main-branch application/test sources encountered WebKit paint/rendering failures. This release does not claim a green full runtime suite. Strict tests are not rerun for this install-only patch under the maintainer's rapid-release request; no application or test source is changed by this release commit.
- The published artifact and Homebrew installation will be verified after packaging.
- No new performance profile: this release changes the install requirement and includes the small corrections listed above, with no performance claim.

## Installation

After the release is published, run `brew update` and `brew upgrade --cask Suehn/scopy/scopy`. New users can run `brew install --cask Suehn/scopy/scopy`.
