# v0.80.2

## Summary

Chinese text with punctuation now renders emphasis correctly. Single-dollar math is supported with bounded delimiter rules that preserve ordinary currency text. Capture tests exercise the production parser, and unused helpers and duplicate repository instructions have been removed.

## Key Changes

- Fix emphasis such as `这是**重点。**请注意` and bold text wrapping formulas using the maintained CJK extension in the existing Markdown pipeline.
- Support `$x_i+y_j$` and Chinese-adjacent `公式$x$之后`. Keep `$5 and $10`, `US$5 to US$10`, price ranges, code, and link destinations literal. Single-dollar math must be nonempty, stay on one line, and have no whitespace immediately inside its delimiters; explicit paired `$5$` is math, so literal dollar pairs require escaping or code.
- Retain one renderer for previews and PNG export; regenerate the JavaScript bundle and asset checksums together and invalidate old render caches. Existing double-dollar and backslash math remain supported.
- Remove the separate test-only clipboard parser and move capture tests onto the production capture stream. Correct detection of KaTeX HTML annotations containing plain TeX such as `x`.
- Remove unused settings subscriptions, obsolete helpers, and two tests without meaningful assertions. Simplify repository guidance and the release skill while retaining product and validation requirements.
