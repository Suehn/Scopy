# v0.80.3

## Summary

Preserve Chinese tables and emphasis when capturing ChatGPT copies that contain both Markdown and HTML.

## Key Changes

- Compare Chinese ideographs independently of spaces and formatting boundaries. The old comparison could reject equivalent Markdown after KaTeX HTML extraction joined table cells and stripped bold, storing that flattened representation instead.
- Keep the authored Markdown and unchanged original HTML payload through the existing capture and rendering pipeline. Unrelated text and corrupted formula representations retain the existing rejection/recovery behavior.
- Add a failing-before/passing-after compact reproduction, a screenshot-inspired paired-MIME fixture, and unrelated-Chinese coverage. The fixture is synthetic; the user's exact source clipboard was unavailable. Existing flattened history requires copying the source again after upgrading.
- Clarify bounded task execution, validation, and release guidance without changing product behavior.
