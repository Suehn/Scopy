# v0.80.5

## Summary

Markdown links now show each website's own icon through a shared native discovery/cache service. This covers arbitrary public hosts across prose, reference citations and result-card sources; it does not add issuer-specific mappings.

## Key Changes

- Discover icons from the public origin homepage and `/favicon.ico`, supporting relative links, attribute order and rel token lists. Requests carry no article path, query, credentials or clipboard body, and reuse the existing public-DNS/redirect and byte-limit checks.
- Share bounded, coalesced fetches and a 256-origin positive/negative cache between preview and PNG. Emit only downscaled 64 px PNGs; unavailable icons keep a compact globe. Cached icons remain available offline.
- Add the independent default-on website-icon setting with Save/Cancel persistence. Article-card enrichment remains independently controlled. Rendering uses the same sanitized AST, local assets and native image adapter; WebView HTTP(S) remains blocked.
- Start the font-readiness timeout after image settlement because WebKit can defer `document.fonts.ready` on pending images. Preserve generation/ownership checks, image deadlines and true-color PNG handling.
